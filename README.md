# G&C Pinturas — landing page

Vite + React + TypeScript + Tailwind v4 + shadcn/ui (Base UI). Español por defecto, inglés en `?lang=en`.

```bash
npm install
npm run dev      # desarrollo
npm run build    # genera dist/ (sitio estático)
```

- Textos ES/EN: `src/i18n/translations.ts`
- Teléfonos y email: `src/lib/contact.ts`
- Imágenes y vídeos optimizados: `public/media`
